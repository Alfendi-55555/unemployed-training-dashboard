# 실업자훈련 성과 대시보드

**질문: 국가기간전략산업직종훈련(국기훈련)은 실업자계좌제보다 '덜 수료하지만 더 취업시키는' 과정인가?
그 취업 우위는 2021~2025년에 유지되었나?**

2026-2학기 산업데이터시각화 개인 프로젝트. Streamlit + Plotly.

## 데이터
- 출처: 한국고용정보원 고용행정통계(eis.work24.go.kr, 원자료: HRD-Net), 2026-11-24 다운로드
  - 실업자훈련수료율현황(년) · 실업자훈련취업률현황(년): 2021~2025, 훈련과정구분 × 훈련직종(KECO)
  - 실업자훈련실시현황(월): 2021-01~2025-12, 훈련기관 시도 × 훈련과정구분 × 훈련직종(KECO)
- 직종코드 대응: 고용노동부, 한국고용직업분류(KECO) 2025 개정 항목표 및 신구연계표
  (https://www.moel.go.kr/info/lawinfo/instruction/view.do?bbs_seq=20241200770)
  - 2018·2025 직종코드의 중분류(35개) 대응 확인과 부록 탭의 신구 대응표에 사용
- 원본 xlsx는 저장소 루트에 그대로 두었고, `prep_data.py`가 `data/` 정리본을 만든다.

## 집계 기준
- 수료율·취업률은 훈련종료연도 기준, 연도별 값만 사용(여러 해 합산·평균 금지). 과정 '전체' 값은 원자료 그대로.
- 훈련 시작 인원은 훈련시작월 기준 연인원(동일인 중복 산정).
- 2025년 KECO 개편으로 직종 단위 계열은 2023/2024 사이에서 끊으며, 해당 코드가 쓰이지 않은 기간의 0은 결측 처리.
- 정리본은 원본 셀 단위로 역대조해 불일치 0건을 확인.

## 실행
```bash
pip install -r requirements.txt
python prep_data.py     # (선택) 원본 xlsx → data/*.csv 재생성
streamlit run app.py
```

## 구성
| 파일 | 내용 |
|---|---|
| `app.py` | 대시보드 (분석 탭 / 부록 탭) |
| `prep_data.py` | 원본 정리·검증 스크립트 |
| `data/rates.csv` | 연도 × 과정 × 직종별 수료율·취업률 |
| `data/monthly.csv` | 월 × 시도 × 과정 × 직종별 훈련 시작 인원 |
| `data/keco_map.csv` | 직종코드 신구연계표(2025 ↔ 2018 세분류) |
| `fonts/` | 나눔고딕(OFL) — 배포 환경 한글 표시용 |
